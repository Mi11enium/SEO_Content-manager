# SEO-тренажёр 🚀

Интерактивный квиз по 50 урокам SEO для контент-менеджера. **300 вопросов** (6 на каждый урок) с тремя типами: множественный выбор, true/false и ввод термина.

## 🎯 Возможности

- **4 режима тренировки:**
  - 📚 **По урокам** — прохождение урока за уроком (по 6 вопросов)
  - 🎲 **Случайная выборка** — 10 случайных вопросов из всего банка
  - 🩺 **Слабые места** — вопросы из уроков, где были ошибки
  - ⏱️ **Экзамен** — 50 случайных вопросов на время
- **Прогресс и streak** (сохраняется в localStorage)
- **Объяснения к каждому ответу** — взяты из соответствующих уроков
- **Тёмная/светлая тема** — автоматически по системным настройкам
- **Mobile-friendly** — адаптивный дизайн, работает на телефоне
- **Без зависимостей и сборки** — открывается прямо из `index.html`

## 🚀 Как запустить

### Вариант 1: открыть локально
Просто откройте `trainer/index.html` в браузере (Chrome/Firefox/Safari).

### Вариант 2: через локальный сервер (рекомендуется)
```bash
# Python
cd trainer
python -m http.server 8080
# откройте http://localhost:8080

# Node.js
npx http-server trainer -p 8080
```

### Вариант 3: GitHub Pages
1. Включите Pages в настройках репозитория
2. Source: `main`, Folder: `/trainer` или `/ (root)` (тогда откройте `/trainer/`)
3. Тренажёр будет доступен по `https://<username>.github.io/<repo>/trainer/`

## 🎓 Источник

Все вопросы основаны на 50 уроках из этого репозитория:
- `01-chto-takoe-seo.md` … `50-seo-checklist.md`

Каждый вопрос содержит ссылку на конкретный урок и объяснение ответа.

## 📊 Статистика

Тренажёр отслеживает:
- **Streak** — дни подряд с активностью
- **Точность** — процент правильных ответов за всё время
- **Пройденные уроки** — сколько из 50 уроков пройдено на 100%
- **Лучший результат по каждому уроку** — цвет плитки (зелёный = пройдено, жёлтый = были ошибки, серый = не пройдено)

## 🛠 Сброс прогресса

Кнопка **«Сбросить»** в правом верхнем углу удаляет весь прогресс из localStorage.
